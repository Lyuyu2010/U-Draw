# U Draw · 绘画版

一个只保留绘画功能的轻量绘画软件（Windows），界面语言与配色取自 PhotoCraft
（ArtCraft 开源图像编辑器）的 **Pro (Dark)** 主题，工具区、选项栏、颜色/笔刷/图层面板的
位置与 PS 一致，但去掉了修图、调色、PSD、文字、滤镜、AI 等一切与绘画无关的部分。

## 安装与卸载

**系统要求**

| 项目 | 最低（能流畅画） | 推荐 |
|---|---|---|
| 系统 | Windows 10 64 位 | Windows 10 / 11 64 位 |
| CPU | 双核四线程（i3-6100 / i5-7200U 级） | 四核（i3-8100 / i5-8250U 级及以上） |
| 内存 | 4 GB | 8 GB |
| 硬盘 | 400 MB 可用（程序目录 176MB） | 1 GB 可用（**建议 SSD**） |
| 显卡 | 集成显卡即可 | 集成显卡 |

内存可以自己估：`180MB + 宽×高×4字节×图层数`。
比如 1600×1200 画 10 层约 260MB，A4 300dpi（2480×3508）画 10 层约 545MB。
想在自己机器上验：`U Draw.exe --bench 结果.txt`。

**安装**：双击 `U Draw Setup 2.15.42.exe` → 选安装位置（默认
`%LOCALAPPDATA%\Programs\U Draw`，装到用户目录，不需要管理员权限）→ 开始安装。
可选建桌面 / 开始菜单快捷方式、安装完立即运行。

静默安装（给别人批量装的时候用）：

```
"U Draw Setup 2.15.42.exe" --silent --dir="D:\Apps\U Draw" --no-desktop --no-startmenu
```

**卸载**：Windows「设置 → 应用 → 已安装的应用」里找到 U Draw 点卸载；
或执行安装目录下的 `U Draw.exe --uninstall`。卸载只删程序和快捷方式，
你自己保存的 `.pcdraw` 工程文件不会被删。

**免安装（绿色版）**：不想装就把整个 `U Draw` 文件夹拷走，双击里面的 `U Draw.exe` 即可。
注意是**整个文件夹**（176MB，含 `_internal`），只拷 exe 是跑不起来的。

当前版本 **v2.15.42**：**彩虹笔恢复变色；细软笔不再「一点一点」**。

本次更新（v2.15.42）：

* **彩虹画笔的颜色回来了**。根因是画笔面板的「笔型」下拉框被无条件写回笔刷，
  下拉框一旦不同步，拖个滑杆就把笔型改成了「圆珠笔」，彩虹笔就不再变色。
  现在只有真的换了笔型才写；你之前被改坏的存档，这次启动会自动修回彩虹笔。
* **细笔 + 低硬度不再出现珠串**。根因是笔点沿曲线按「参数」均匀取，而曲线参数
  和弧长不成正比 —— 手快时笔点一头密一头疏（实测 0.2~2.2px 来回摆）。
  现在按真正的弧长取点，中线亮度从「176~222 起伏」变成一条平线。
  顺带把隔点采样的间距压在笔径 12% 以内，纸纹颗粒也随笔径收放。

本次更新（v2.15.2）：

* **轻压真的能画出来了**：数位板送来的压力大多落在 0.05~0.4 这一段，直接线性乘笔径

  再也不用记 `Ctrl+G` / `Ctrl+Shift+G`。
* **背景层钉住了**：白色背景层固定在最底层——**拖不动、不能上移下移、删不掉、不会进组**，
  图层行上直接写着「固定底层」。万一以前拖乱了（或旧文件里的背景层跑上去了），
  而且铺满画布的色块拖动时**离原位 8px 内会自动吸附**，手一抖也不会留缝。

* **文字先有了独立图层**（v2.1.2 起进一步升级成「可再编辑的文字对象」）：

* **文字有自己的颜色**：选项栏里的「颜色」色块只作用于文字，**不再跟随前景色**；

* **最近使用颜色**：右侧颜色面板底部新增「最近」一行，拖色板 / 吸管取色都会记进来，
  **关掉软件再打开还在**（存在系统设置里，不占项目文件）。
* **触摸板**：双指**捏合**缩放画布，双指**滑动**平移画布（鼠标滚轮仍然是缩放）。

* **新增「导出 PSD 工程（分层）」**：`文件 → 导出 PSD 工程…`，把当前文档写成 Photoshop 能直接

上一版（v2.1.0）：新增 **对称绘图**、**涂抹工具**、**文字工具（含原版字体库）**，

* **对称**：右侧新增「对称」面板 —— 关 / 垂直（左右）/ 水平（上下）/ 四象限 / 径向（2~24 份）。
  对称不是「画完再镜像一份」，而是**每一颗笔点就照轴复制出去**，所以压感、抖动、颗粒
  左右两半完全一致。画笔、橡皮、涂抹都吃对称；光标会把镜像位置的笔尖一起画出来，
  落笔前就知道会画到哪儿。「点选轴心」后点画布任意位置即可移动对称轴，「轴心居中」回画布正中。
* **涂抹**：`S`。按住拖动，把笔下的颜色一路抹开（默认力度 20%，可调）。过渡按笔点间距归一化，
  不会一步叠死、出现分层色带。在透明图层上涂抹会连透明
  一起抹，边界自然淡出；同样支持对称，画对称的火焰 / 云 / 头发特别省事。
* **文字**：`T`。在画布上（或画布外的灰色工作区）点一下就**就地打字**（虚线框里直接输入，
  所见即所得），`Enter` 换行，`Esc` 落字；顶部选项栏的 `✓` / `×` 可手动确认或取消。
  不想要的内容点 `×`，或删空再落字即可删除。
  选项栏可挑**文字库**里的字体（原版 PhotoCraft 自带的
  4 套 OFL 开源字体 + 本机中文字体，每项都用它自己的字体显示）、字号、粗体 / 斜体（对齐按钮 v2.1.2 已移除）。
  落字后文字变成图层像素，可以接着用画笔改。
* **油漆桶消白边**：原来的填充只处理「半透明」的边缘像素，在白底上画的黑线边缘是
  **不透明**的灰色抗锯齿像素，于是永远留一圈白边（PS / PhotoCraft 的老毛病）。
  现在按**覆盖度**把这圈像素算出来再过渡：`结果 = 原像素 + (填充色 - 背景色) × (1 - 覆盖度)`，
  纯墨色原样保留、纯背景换成填充色、中间自然过渡 —— 放大到 800% 也看不到白缝。

上一版（v2.0.0）：换了新图标、重绘了左侧工具栏图标、改名 U Draw、加了安装包；
另外补上了 **「关于」页的创作者信息**、**「赞助」入口**（扫码支持），
并把 22 个画笔调节项逐个量过一遍，确认都能真正改变笔迹（见第五节「参数体检」）。

这次又修了四处：

* **流量和不透明度分工明确**：不透明度是天花板——42% 画多少遍都停在 42%，不会越描越黑；
  流量是往上爬的速度——调低就是淡淡一层，同一处反复画会一笔比一笔深，但不会越过天花板。
* **移动工具的自动选择**：跳过锁住的图层（不再选中一个点不动的东西）；
  按住 **Ctrl** 点画布可以加选图层、**Shift** 连选，选中多个后拖一下就能整体移动。
* **滑杆点哪儿跳哪儿**：自绘滑杆，点凹槽直接跳到点击位置，不用再一点点挪；
  拖动时试笔预览降到约 9 帧/秒、画布不再无谓重画，手柄本身逐帧跟手。
* **弹窗全中文**：保存 / 不保存 / 取消、退出 / 取消，以及各种提示框，不再是
  Save / Discard / Cancel / Yes / No / OK。

## 一、安装 / 运行

**方式 A（推荐）**：双击 **`U Draw 2.9.1 安装包.exe`**
- 默认装到 `C:\Users\<你>\AppData\Local\Programs\U Draw`，**不需要管理员权限**
- 可选：创建桌面快捷方式、开始菜单快捷方式、装完立即运行
- 装完会在「设置 → 应用 → 已安装的应用」里登记，可从这里卸载；
  也可以直接运行安装目录里的 `uninstall.exe`，或开始菜单里的「卸载 U Draw」

**方式 B**：直接双击 **`U Draw.exe`**（绿色单文件，免安装，无需 Python 或任何依赖）。
首次启动约 1～3 秒。

启动即得到一张 1920 × 1080 白色画布，可以直接画（画布自动适应窗口并居中）。

## 四、数位板压感

1. 先用厂商驱动（如 Gaomon 的 GaomonTablet）确认笔正常工作。
2. **驱动里要打开「Windows Ink」**（Qt 通过 Windows Ink 读取压力；关闭时只能拿到 0/1 两档）。
3. 回到软件里，状态栏右侧的「笔压」条会随落笔实时变化 —— 这是判断压感是否生效最直接的方式。
4. 画笔面板里 10 种画笔都用真笔迹缩略图列出，可以滚轮上下滚动；
   每格里的白色笔迹是**真引擎画出来的试笔样品**，不是图标。
   点任一项都会把该画笔的完整参数装到当前笔上，下面滑杆和开关随之更新。
5. 压感只有**一个开关**，勾上就同时管「粗细」和「浓淡」：
   - 数位板 → 用笔的真实压力（画得越重越粗越实）
   - 鼠标 / 驱动没送压力 → 按运笔速度模拟（慢拖变粗、快划变细）
   - 不勾 → 一律等粗，圆珠笔 / 马克笔就是这种手感
6. **状态栏的「笔压·笔 / 笔压·模拟」是判断压感有没有生效的最快方式**：
   显示「·笔」说明数位板真实压力已读到；显示「·模拟」说明软件没收到压力，
   去数位板驱动里把 **Windows Ink** 打开，再在画布上重新落笔。
7. **抬笔时压力会瞬间报 0**，如果不处理，笔画末端就会拖出一小团墨点。这里做了「压力保持」：
   抬笔那一帧沿用最后一帧的有效压力，所以笔迹是干净收尾的。
8. 笔尾橡皮（Wacom 等笔的 Eraser 端）会自动切成橡皮，抬笔后恢复原来的工具。

### 画笔参数一览（六个分组，点组名就能折叠）

| 分组 | 参数 | 说明 |
|---|---|---|
| 笔尖形状 | 大小 / 圆度 / 角度 / 硬度 / 间距 | 直径；圆度决定扁不扁（100% 正圆）；角度让扁笔尖转方向；硬度越低边缘越柔；间距是两个笔点相距多少（占直径比例，调大能画出一个个点） |
| 形状动态 | 大小抖动 / 圆度抖动 / 角度抖动 / 散布 / 散布数量 | 每个笔点随机变化的幅度，模拟手绘的不规则；散布让笔点偏离笔画中线 |
| 传递 | 不透明度 / 流量 / 流量抖动 | **不透明度是天花板**：同一个颜色怎么描都不会超过它（42% 就是 42%，画十遍也一样）；**流量是往上爬的速度**：调到 30% 就是淡淡一层，同一处反复画会一笔比一笔深、慢慢逼近不透明度。想突破天花板就换个颜色，或者把不透明度调高 |
| 纹理 | 颗粒 / 颗粒粗细 / 湿边 | 颗粒＝纸纹强度（铅笔 / 蜡笔的粗糙感）；颗粒粗细 1px 像铅笔纸纹，5~6px 像蜡笔的成块颗粒；湿边给水彩那种边缘积色 |
| 颜色动态 | 色相 / 饱和度 / 明度抖动 | 每个笔点颜色的随机偏移，画彩色铅笔的杂色很有用 |
| 笔锋 | 起笔渐细 / 最小直径 | 起笔收笔自动变细；最小直径限制压到最轻时还剩多细 |

抖动修正不在上面六组里 —— 它改的是**整条笔迹的走向**，不是单个笔点的样子：
往右拖，手抖被吃掉、长直线变直；收笔补齐已内置，笔迹保证停在抬笔的位置。

### 参数体检：22 个调节项逐个量过（v2.0.0 起）

「滑杆能动」和「滑杆真的改了笔迹」是两件事。`app/_param_audit.py` 的做法是：
挪动面板上某一根滑杆 → 用真引擎在 720×300 画布上画一条带压力变化的 S 形笔画 →
在「有墨的像素」上比两张图的平均色差（0~255，≥3 就算肉眼看得出）。

| 参数 | 低值→高值 | 差异 | 参数 | 低值→高值 | 差异 |
|---|---|---|---|---|---|
| 大小 | 10 → 56 px | 143.5 | 流量抖动 | 0 → 80 % ¹ | 72.9 |
| 圆度 | 100 → 35 % | 92.9 | 颗粒 | 0 → 80 % | 21.8 |
| 角度 | 0 → 70° | 61.8 | 颗粒粗细 | 2 → 8 px ² | 11.3 |
| 硬度 | 100 → 0 % | 86.9 | 湿边 | 0 → 85 % | 26.5 |
| 间距 | 5 → 120 % | 35.3 | 色相抖动 | 0 → 80 % ³ | 14.7 |
| 大小抖动 | 0 → 70 % | 57.4 | 饱和度抖动 | 0 → 80 % ³ | 15.4 |
| 圆度抖动 | 0 → 70 % | 37.2 | 明度抖动 | 0 → 80 % | 19.8 |
| 角度抖动 | 0 → 90 % | 42.1 | 起笔渐细 | 0 → 70 % ⁴ | 33.9 |
| 散布 | 0 → 80 % | 44.7 | 最小直径 | 10 → 90 % | 22.8 |
| 散布数量 | 1 → 6 | 55.5 | 抖动修正 | 0 → 70 % | 55.0 |
| 不透明度 | 100 → 35 % | 107.0 | 压感开关 | 关 → 开 | 90.3 |
| 流量 | 100 → 25 % | 129.2 | | | |

**22 项全部生效。** ¹ 流量抖动是「墨量沿笔画起伏」，不是逐笔点乱跳 —— 笔点会被叠成
一整片，逐点抖动根本看不出来；它现在是给整笔蒙一张按文档坐标平铺的平滑噪声（镜像拼接，
没有接缝），所以任何间距下都能看出浓淡。
² 颗粒要先把间距拉大才量得出来，笔点重叠太密会把纸纹平均掉。
³ 灰墨看不出色相 / 饱和度变化（灰度饱和度为 0），这两项用饱和的红色测。
⁴ 起笔渐细只影响起笔后头一小段，所以要限定区域比对，否则会被整张图稀释。

体检时顺手修掉的三个真问题：

* **颗粒贴图对比度只有 1/3**：早先用 `setPixel(x, y, int)` 写灰度图，Qt 会把这个数
  当成 RGB 再按 qGray 换算（≈0.34 倍），于是颗粒一直是一层很淡的灰雾，`颗粒粗细`
  几乎看不出变化。改成直接按字节造 Grayscale8 数据、再把对比度拉回 0~255，
  现在 alpha 是 50~255，铅笔 / 蜡笔的纸纹才真的「吃得掉墨」。
* **删掉两个没人用的参数**：`pull_string` / `catch_up` 只写在数据结构里，引擎从来不读，
  UI 也没有入口 —— 已从 `Brush` 里移除，笔刷预设文件不再写这两个空字段（老文件仍能正常读）。
* **流量形同虚设**：笔点的 alpha 里直接带流量，间距 5% 时二十个笔点叠下来一律到顶，
  100% 和 60% 画出来一样黑。现在按间距反解每个笔点该有多浓
  （a = 1-(1-flow)^spacing），画一遍正好到流量；低流量时再「隔几个笔点画一个、
  每个浓一点」，避开 QPainter 对低于 0.8% 的贴图直接不画的毛病。

## 六、关于「先安装原版再删改」这件事（说明）

原版 PhotoCraft 是 20 多万行 Rust + wgpu 的完整 PS 级图像编辑器（500+ 条命令、PSD 解析、调整图层、文字、
滤镜、AI 桥接……）。它的发布物是**编译后的二进制**，功能清单在编译期就被固化了，没有开关能「删掉一半工具」；
要真正裁剪只能改源码重编译，而那需要 Rust 工具链 + MSVC Build Tools（数个 GB）、完整依赖树，
并且要在几十个 crate 里同步删命令、删菜单、删快捷键、删状态，编译期错误极多 —— 那不是「优化成绘画软件」的合理路径。

所以这里的做法是：**装原版做参照，按它的界面语言和配色重做一个只含绘画功能的原生实现**。
结果是你要的东西：一个 60 MB、双击即开、50 层起步、压感正常、快捷键和 PS 一致、专用于画画的 exe。
如果后面你希望在原版 Rust 工程上做源码级裁剪（保留它的 GPU 合成器与 PSD），那是另一条工程路线，
需要先装 Rust + VS Build Tools，我可以按这个方向再做一版。

补充：原版 0.12.0 的解压版已经放在 `_photocraft_original/` 里，可以直接双击它的 `photocraft.exe` 打开对比
（首次运行会在同目录生成 `PhotoCraftData` 设置目录）。它需要 GPU 走 Vulkan/DX12，启动前会探测注册表；
在我这边的隔离环境里，这一步被安全策略拦了，所以只截到配色与源码，界面截图用的是我自己实现的版本。
你本机正常双击不受这个限制。
